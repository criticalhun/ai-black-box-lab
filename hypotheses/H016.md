# H016 — Kauzális munkamegosztás a két réteg között

**Státusz:** SUPPORTED (2026-10-09, EXP018, 3/3 friss seed)
**Tesztelve:** EXP018 (modellek: EXP017, seed 3, 4, 5)
**Rögzítve:** 2026-10-09 — az EXP016 megfigyeléseiből, a seed 3–5 tanítása ELŐTT.

## Állítás (seedenként, test acc a "=" pozíción végzett 2D Fourier-osztály-kivetítés után)
- 1. réteg MLP, same_freq kivéve → ≤ 0.20
- 1. réteg MLP, a_only + b_only kivéve → ≥ 0.99
- 0. réteg MLP, a_only + b_only kivéve → ≤ 0.75

## Érvényesség
Végső modell test acc ≥ 0.99, különben INVALID. SUPPORTED 3/3, PARTIAL 1–2, REJECTED 0.
